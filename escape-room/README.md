# Escape Room de Computação — O Sistema Foi Invadido
1. Extraia o zip numa pasta nova (fora do OneDrive). NÃO misture arquivos: backend/ e frontend/ ficam separados.
2. Em backend/: copie .env.example para .env, preencha DB_PASS e JWT_SECRET.
3. Em backend/: npm install  →  npm start
4. Abra http://localhost:3000 (Ctrl+F5)
